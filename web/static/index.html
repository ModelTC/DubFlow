QUICK GUIDE

开始前，了解这几件事

目前支持什么？

原视频语言自动检测；请选目标语言。当前可选语种以工作台显示为准，视频需包含音轨。

时长策略怎么选？

关闭“视频时长自适应”时保持原片时长，译音超时先尝试缩译、再调速。开启后，适合独立处理的单镜头语句会按译音延长或缩短画面；插帧与取帧只作用于这些片段。处理更慢，局部运动和背景音节奏可能变化；切镜、多人交叠或快速运动仍可能出现伪影。

如何处理多人和背景声？

系统用 Qwen 识别对白、匹配说话人并生成配音；SAM-Audio Large-TV 分离对白与背景，复用 ASR 时间提示；翻译由配置的服务后端完成，TBDub Student 由 LightX2V 服务完成，不做译文／成片反复核验。人脸不可靠的片段仅处理音频，仍可能漏句、配错台词或残留原语言对白。时间对齐不等于内容正确，请完整预览结果。

为什么需要等待？

视频 worker 按工作台显示的数量并发，翻译模型共享；超出后排队。模型在启动时预热并常驻。进度按处理阶段更新，不是精确剩余时间。

谁能看我的素材？

上传与结果保存在这台服务器，不会发送给额外的付费生图或视频 API。公网访问时，上传与下载会经当前入口的 Cloudflare 或 Gradio 隧道中转。没有登录密码；当前浏览器会话用于隔离任务，清除 Cookie 后可能无法找回记录。不要上传无权处理或不适合保存在该服务器的敏感素材。

输出是什么？

生成视频、可用的对比视频、原文、译文和处理报告。文本是识别与翻译记录，不是时间轴字幕文件。处理完成不代表台词已通过内容核验，请在发布前检查结果。
